* merits of the key-based language
- can specify any number of arguments from 0 to all of them.  There are sensible defaults.  This makes common actions less verbose (fewer characers) than less common ones.  Because options can be specified in any order, users can be flexible with the semantics of certain combinatinos.  [examples]



* Flow
- invoke magneto (use s-m)
- apply 0-n settings
- invoke magneto (use s-m)
- select a window for the action (if not already selected)

* Options
** source

magneto was invoked

|---------------------+------------------------------------------------------------------------------------------------------------+-----|
