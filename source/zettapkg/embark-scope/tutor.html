1. Overview

This package adds functionality for quickly accessing bookmarks within the current projects.

2. Commands

2.1. bookmark-in-project-delete-all

Delete all bookmarks in the project. If optional argument NO-CONFIRM is non-nil, don’t ask for confirmation.

(fn &optional NO-CONFIRM) 

(call-interactively #'bookmark-in-project-delete-all)

2.2. bookmark-in-project-jump

Jump to a bookmark in the current project. 

(call-interactively #'bookmark-in-project-jump)

2.3. bookmark-in-project-jump-next

Jump to the next bookmark. 

(call-interactively #'bookmark-in-project-jump-next)

2.4. bookmark-in-project-jump-other-frame

Jump to a bookmark in another frame, see ‘bookmark-in-project-jump’. 

(call-interactively #'bookmark-in-project-jump-other-frame)

2.5. bookmark-in-project-jump-other-window

Jump to a bookmark in another window, see ‘bookmark-in-project-jump’. 

(call-interactively #'bookmark-in-project-jump-other-window)

2.6. bookmark-in-project-jump-previous

Jump to the previous bookmark. 

(call-interactively #'bookmark-in-project-jump-previous)

2.7. bookmark-in-project-toggle

Create or delete a bookmark on the current line. 

(call-interactively #'bookmark-in-project-toggle)

3. Options

3.1. bookmark-in-project-name

  • Current value: bookmark-in-project-name-default-with-context

    Function to call that returns the bookmark name to use. A nil return value will fall back to the ‘path:line’. 

(customize-variable 'bookmark-in-project-name)

3.2. bookmark-in-project-name-fontify

  • Current value: bookmark-in-project-name-default-fontify

    Function to call that sets font properties for bookmark display.

    This takes and returns a string, optionally setting font properties, set to ‘identity’ to use plain text. 

(customize-variable 'bookmark-in-project-name-fontify)

3.3. bookmark-in-project-project-root

  • Current value: bookmark-in-project-project-root-default

    Function to call that returns the root path of the current buffer. A nil return value will fall back to the ‘default-directory’. 

(customize-variable 'bookmark-in-project-project-root)

3.4. bookmark-in-project-use-completion-ivy

  • Current value: t

    Use the IVY completion framework (when available). 

(customize-variable 'bookmark-in-project-use-completion-ivy)

3.5. bookmark-in-project-verbose-cycle

  • Current value: t

    Show messages when cycling between bookmarks. 

(customize-variable 'bookmark-in-project-verbose-cycle)

3.6. bookmark-in-project-verbose-toggle

  • Current value: t

    Show messages when toggling bookmarks on/off. 

(customize-variable 'bookmark-in-project-verbose-toggle)

4. Functions

4.1. bookmark-in-project-name-default-fontify

  • Signature: (bookmark-in-project-name-default-fontify name)

    Apply face property to the bookmark NAME (for display only).

    (fn NAME)

4.2. bookmark-in-project-name-default-with-context

  • Signature: (bookmark-in-project-name-default-with-context)

    Return the name used to create the bookmark with contextual information.

4.3. bookmark-in-project-name-default-with-line

  • Signature: (bookmark-in-project-name-default-with-line)

    Return the name used to create the bookmark with the line number.

4.4. bookmark-in-project-project-root-default

  • Signature: (bookmark-in-project-project-root-default)

    Function to find the project root from the current buffer. This checks ‘ffip’, ‘projectile’, ‘project’ & ‘vc’ root.
