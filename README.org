#+title: Zetta Emacs

An Emacs configuration distro: an always-loaded bootstrap layer plus
selectively loaded modules (chosen via =zetta-modules!= in
=~/.zetta.el=), with packages managed by elpaca against a committed
lockfile (=elpaca-lock.el=).

* Supported Emacs versions

CI builds and tests every change against:

- Emacs 29.4
- Emacs 30.2

Released versions only.  Pretest and snapshot builds are not tested
or supported: their version numbers don't pin the Lisp sources (two
builds both calling themselves "31.0" can differ in core macros and
setters).  Emacs 31 will join the matrix as a pinned entry once 31.1
ships.

* Installation model

=bin/zetta install= builds every package from source on your machine,
against whatever Emacs you bring.  Nothing prebuilt is distributed:
byte-compiled artifacts are only guaranteed correct for the exact
Emacs build that produced them, and cross-compiling on CI for other
platforms and Emacs builds produces subtle incompatibilities (we
tried).  A full first build takes on the order of an hour; after
that, installs are incremental.

If you switch to a different Emacs build over an existing install,
rebuild against it: =rm -rf elpaca && bin/zetta install=.
=bin/zetta doctor= includes a bytecode census that flags any =.elc=
compiled by a different Emacs than the one it is run with.
